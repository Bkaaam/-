# 听见 · 雅思阅读室

手机优先的个人雅思 Academic 阅读书架，收录用户提供的剑桥雅思 11–21 阅读资料。通过访问密码解锁，部署于 GitHub Pages。

**网站：[打开阅读室](https://bkaaam.github.io/-/?v=4.9)**

## 当前版本 4.9

- 保留原有阅读/听力收藏、笔记、精确颜色标记、进度、听力原文编辑和草稿；移除入口不会删除旧数据。听力语料库仍可查看及手动添加。

- 译文及段落概述默认隐藏；跨句划选逐句对照。常见词典义项与原句参考译文明确区分。

## 保存与备份

学习数据仍使用 `ielts-room-v2` 数据库的 `notes`、`vocab` 原有记录，没有数据库升级、清空或破坏性迁移。个人修订存入 `notes.readingTranslations`，备份同时包含原有听力编辑和草稿。

在“设置”中选择“导出全部学习记录”下载 JSON 备份。换手机、换浏览器或清理网站数据前先备份，再用“恢复学习记录”导入。数据保存在当前浏览器，不会通过 GitHub 自动同步。新网站版本只更新程序和加密资料。

## 项目结构

- `site/`：静态页面、程序及加密学习资料。
- `site/fast.js`：按文章加载、缓存和解密。
- `site/reading-focus.js`：阅读模式、译文对照与个人修订、移除听力入口。
- `site/study-tools.js`：阅读自然段、颜色标记、笔记和手动生词。
- `site/sw.js`：离线程序缓存；保留旧资料缓存以兼容既有数据。
- 听力程序及加密资料留存以兼容旧记录，但不再提供逐句精听界面。
- `.github/workflows/pages.yml`：GitHub Pages 发布流程。

资料来自用户提供的文件，扫描识别可能存在错字。仓库只保存加密后的资料，不包含原始 PDF 或访问密码。词典采用 ECDICT，许可见 `site/dictionary-LICENSE.txt`。
