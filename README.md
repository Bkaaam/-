# 听见 · 雅思阅读与逐句精听阅读器

一个适合手机使用的雅思学习网页。把阅读文章、听力原文、考试原声和生词笔记放在同一个阅读器里，按自己的节奏每天积累。

**[打开在线阅读器 →](https://bkaaam.github.io/-/)** · [查看版本发布](https://github.com/Bkaaam/-/releases) · [查看部署状态](https://github.com/Bkaaam/-/actions)

> 访客无需注册，也不需要登录 GitHub。打开网页，输入站点所有者提供的访问密码即可。公开仓库不列出访问密码。

## 有哪些功能？

| 功能 | 使用方式 |
| --- | --- |
| 手机阅读 | 自适应手机屏幕，支持字号、行距调整和夜间模式 |
| 分层目录 | 剑桥 11–21 学术类，按书册 → Test → 阅读第 1 / 2 / 3 篇或听力 Part 1–4 查找 |
| 点击查词 | 轻触英文单词，即时查看词典释义、音标和当前原文例句，可播放读音 |
| 生词本 | 收藏单词、记录本句含义，并返回原文章复习 |
| 原声播放 | 播放配对的考试原声，拖动进度、前后跳转、调整速度 |
| 点词定位 | 播放过程中点击已可靠对齐的词，从对应原声位置继续听 |
| 逐句精听 | 播放一句后暂停，支持重听、上一句、下一句、单句循环和隐藏原文 |
| 参考答案 | 在阅读或听力页面查看相应 Test 的参考答案文本 |
| 学习记录 | 保存本机学习位置与完成标记，可导出并恢复生词和进度 |
| 音频缓存 | 按段缓存加密录音，方便在弱网环境下重复练习 |


## v1.1：快速解锁与话题语料

- 解锁目录由原来的约 5.32 MB 整包拆为约 14 KB 加密目录；登录前预取加密目录，输入密码后只验证小目录。
- 原文、时间轴、对应词典按章节加载，不再为进入首页下载全部资料。词典随本章一起加载，章节打开后点词无需在线查词。
- 音频首次下载自动加密缓存；再次进入同一章节或点击缓存按钮复用本机资料，同一请求合并，显示下载百分比。首次未缓存的原声仍受网络带宽影响，不承诺所有网络秒开。
- 新增 **[话题语料](https://bkaaam.github.io/-/#topics)**：按主题整理词汇、表达与听力考点，以后可继续添加专题。

首个话题为“日常生活与社交”，覆盖剑11 T1 Part1 / T2 Part2，剑13 T2 Part1 / T3 Part1，剑14 T1 Part1，剑16 T2 Part1 / T3 Part1，剑17 T2 Part1 / T3 Part1。

包含 65 个重点词汇、35 个表达、8 组听力技巧。每个词条附中文含义、考点提示、原文证据及来源，可播放预生成示范读音和小体积语境原声片段；支持搜索、场景筛选、跨篇重复筛选、掌握标记和随机听写。

频次严格限定于这 9 份语料，其中 14 项在多篇重复；单篇重点不标为全雅思高频。示范读音为美式合成语音，语境原声来自用户材料，自动对齐片段可能略有偏移。专题正文和语音仍加密，掌握标记包含在原有学习记录备份中。

更新后如仍显示旧版，请刷新或关闭网页后重新打开；无需清除浏览器学习记录。

## 收录范围

- 剑桥雅思 **11–21 Academic（学术类）**，每册 4 个 Test。
- **132 篇阅读文章**、**176 个听力 Part**及对应原声，附参考答案。
- **16,623 个预置单词示范发音**，用于减少对手机系统语音引擎的依赖。
- 剑桥 12 的原书 Test 5–8，在本站对应 Test 1–4。

原文由使用者提供的 PDF 在本机提取和 OCR 整理，录音来自同批资料。资料以加密形式保存在仓库中，未提供原始 PDF 或未加密的考试录音。

### 关于文字和时间轴精度

文字经过 OCR，仍可能存在个别识别错误，答案以原书为准。时间轴由本机语音识别与原文匹配生成，不等同于逐字人工校对。

- 约 **92.98%** 的听力单词具有可靠声学时间点；未可靠定位的词会明确提示。
- 约 **87.30%** 的句子可使用原声逐句播放，其中部分明确标为“原声前后文”，可能包含少量相邻语音。
- 其余句子标为“辅助朗读”，使用设备合成语音，不能当作考试原声。
- 词典提供不同词性下的通用释义，文章中的具体含义需结合例句判断，也可记录自己的词义笔记。

## 手机怎么用？

1. 用小米浏览器、Chrome 或 Edge 打开 **https://bkaaam.github.io/-/**。
2. 输入访问密码，选择“阅读书架”或“逐句精听”，再选择书册和 Test。
3. 阅读时轻触单词查词；听力暂停时点词查词，播放时点词定位到原声。
4. 如需专注练习，打开“逐句精听”，配合“单句循环”和“隐藏原文”。

浏览器菜单中可选择“添加到桌面”或“安装应用”，以后从手机桌面进入。首次打开需要下载文字与词典资料包；考试录音按所选章节加载，不会一次下载全部音频。

预置单词示范发音采用美音；听力中已定位的词优先播放考试原声。音标以英式为主。个别辅助朗读及全文朗读需要设备支持英语文字转语音。

## 生词和进度会保存在哪里？

学习记录保存在**当前设备、当前浏览器**的 IndexedDB 中，不会自动同步其他手机。

- 在“设置”里点击“导出生词与进度”，保存备份文件。
- 换设备后，在新设备打开阅读器，选择“恢复学习记录”。
- 清理浏览器数据可能清除本机进度与音频缓存，建议定期备份。

## 密码与公开发布

网页代码公开，文章、答案、录音及词音以密文存放。访问密码在浏览器内派生解密密钥，不发送给服务器，也不写入网页源码。

使用 **PBKDF2-SHA256（310,000 次）+ AES-256-GCM**。六位密码强度有限，知道密码的人也可以解锁，不能保证只有站点所有者本人访问。共用设备上使用后，可点击右上角锁定阅读器。

网站没有主动设置地区过滤；具体访问速度和连通性由当地网络与 GitHub Pages 决定。

## 项目文件

```text
.
├── README.md                       # 项目说明（就是本页）
├── .github/workflows/pages.yml      # GitHub Pages 自动发布流程
└── site/
    ├── index.html                  # 页面入口
    ├── app.js                      # 阅读、查词、精听及解密逻辑
    ├── style.css                   # 手机与桌面布局
    ├── config.json                 # 公开解密参数，不含密码或密钥
    ├── library.bin                 # 加密原文、答案、词典和时间轴
    ├── media/                      # 加密听力原声
    ├── pronunciation/              # 加密单词发音
    ├── manifest.webmanifest         # 手机桌面应用信息
    └── sw.js                       # 网页与密文缓存
```

英汉词典与音标来自 [ECDICT](https://github.com/skywind3000/ECDICT)，许可见 [`site/dictionary-LICENSE.txt`](site/dictionary-LICENSE.txt)。
