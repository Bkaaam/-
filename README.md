# 听见 · 雅思阅读器

[打开网站](https://bkaaam.github.io/-/) · [查看部署状态](https://github.com/Bkaaam/-/actions)

适合安卓手机使用的剑桥雅思 11–21 Academic 阅读与听力学习网页。网站公开可访问，输入个人密码后解锁加密的学习资料；无需注册账号。密码不写在网页源码里。阅读进度、生词、标记和笔记保存在当前浏览器的 IndexedDB 中，请定期在「设置」中导出备份。

## 功能

- 阅读书架按册、Test、Passage 收录 132 篇文章。文章按原文自然段排版，每段标注阿拉伯数字，段落概述默认隐藏，点击后展开；23 篇 OCR 原稿缺少可靠段落分隔，按句子边界重建，页面中有提示。段落小结和文章梗概由译文自动摘取，仅供理解和复习，建议结合原文核对。
- 点击阅读或听力原文中的单词，可查看音标、读音及语境含义；句子翻译默认隐藏，按需展开。长按或拖动选择文字后，可只给选中的部分上色并写笔记，不会自动标记整句。整句标记按钮仍可使用。
- 听力书架收录 176 个 Part。自动优先使用较小的录音，取消音频版本选择、查看参考答案和名词听写入口。支持拖动跳转、倍速、逐句精听、词语定位；流式模式可边听边缓存，小米浏览器默认采用完整 MP3 兼容播放。
- 精听新增「编辑原文」：逐句纠错、补充文字，并可修改句子的原声时间。修改稿和草稿保存在原 `notes` 记录中，纳入已有导出与恢复功能。未改词保留可靠的原声位置，新补的词不会被分配虚构时间；旧生词和笔记保留。
- 原文编辑保留时间戳的原始精度，修复折叠时间框阻止保存的问题。保存中有明确反馈；无效字段会显示具体句号并展开定位。保存遇到存储不足、中断或超时，会保留编辑内容并提供草稿备份导出，不会误报保存成功。
- 兼容播放支持最多三路分段并行下载，校验并复用已有片段，网络中断后可以续传。完整录音仍经 AES-GCM 校验；最近三段解密结果只在解锁会话的内存中复用，锁定后清除，磁盘缓存只存密文。播放高亮适度降低刷新频率，减少手机界面开销。
- 生词本只保留「阅读生词汇」和「听力语料库」。旧听力名词、其他听力收藏及之前自行添加的生词均归入听力语料库；首次打开新版时自动迁移，原记录键、例句、含义、笔记和标记保留。迁移后新手动生词仍直接加入当前选中的词库。
- 小米浏览器自动使用完整 MP3 兼容播放，可复用旧缓存。其他浏览器流式加载失败时自动尝试兼容播放，必要时尝试原音质；用户可手动选择播放方式。底部可展开系统播放器。手机播放栏会根据实际高度为正文留出空间，底部导航适配四个入口和安全区域。
- 话题语料板块及网站内的配套资料已移除，之前从该板块收藏的生词仍保留在听力语料库。切换模块后可回到此前打开的文章或听力 Part。

## 使用与数据

在手机浏览器打开 [网站](https://bkaaam.github.io/-/)，输入密码即可。建议用同一个浏览器学习并定期备份；清理浏览器网站数据会删除本机学习记录。新版沿用原有的 `ielts-room-v2` 数据库及 `notes`、`vocab` 存储项，没有重置旧生词和笔记。网站的可用速度也取决于当前网络与 GitHub Pages 的连通性。

原文来自用户提供的资料，部分内容经 OCR 识别，可能有识别误差；翻译、小结和词义提示为辅助学习内容。录音与文字的词级定位由声学对齐生成，个别边界可能偏移。仓库仅放加密后的学习资料，不包含原始 PDF 和明文密码。

## 项目结构

- `site/`：GitHub Pages 静态网站及加密资料。
- `site/fast.js`：分章节加载、缓存及解密。
- `site/stream-player.js` 与 `site/sw.js`：加密音频分段请求、播放和自动缓存，密钥仅存于解锁会话内存。
- `site/study-tools.js`：阅读段落、标记笔记、音质切换等学习工具。
- 资料处理和校验脚本保存在本地工作目录的 `processing/`，不随网站部署。
- `.github/workflows/pages.yml`：推送到 `main` 后部署 GitHub Pages。
