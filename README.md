# 听见 · 雅思阅读器

为 GitHub Pages 准备的完整静态站点。`site/` 包含可发布文件，`.github/workflows/pages.yml` 使用官方 Actions 发布。

需要仓库管理员在 Settings → Pages → Build and deployment 中选择 GitHub Actions。推送到 main 或手动运行工作流后，Actions 会给出实际 github.io 地址。

无需访客账号。文章、答案、录音及词音均为密码加密数据；访问者在浏览器内输入访问密码解密。不要把未加密 PDF、原始音频、构建密码或密钥提交到仓库。

132 篇阅读、176 段原声、16,623 个预置词音。原文由用户提供的资料本地 OCR 提取，可能有识别错误。机器声学时间轴不能等同逐词人工校验，未可靠定位的词会提示；原声上下文窗口会标注，其他句子为辅助朗读。

所有资源使用相对路径，可用于 GitHub Pages 项目站点。进度与生词存本机浏览器，可导出备份。没有主动地区限制；实际连通性取决于用户当地网络。
