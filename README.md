# 听见 · 雅思阅读器

[打开网站](https://bkaaam.github.io/-/) · [查看部署状态](https://github.com/Bkaaam/-/actions)

适合安卓手机使用的剑桥雅思 11–21 Academic 阅读与听力学习网页。网站公开可访问，输入个人密码后解锁加密的学习资料；无需注册账号。密码不写在网页源码里。阅读进度、生词、标记和笔记保存在当前浏览器的 IndexedDB 中，请定期在「设置」中导出备份。

## 功能

- 阅读书架按册、Test、Passage 收录 132 篇文章。文章按原文自然段排版，每段标注阿拉伯数字和中文小结；23 篇 OCR 原稿缺少可靠段落分隔，按句子边界重建，页面中有提示。段落小结和文章梗概由译文自动摘取，仅供理解和复习，建议结合原文核对。
- 点击阅读或听力原文中的单词，可查看音标、读音及语境含义；句子翻译默认隐藏，按需展开。长按或拖动选择文字后，可只给选中的部分上色并写笔记，不会自动标记整句。整句标记按钮仍可使用。
- 听力书架收录 176 个 Part。提供原音质和省流量两种加密音频，默认加载省流量版；其文件总体比原版缩小约三分之一。网络中断时会重试，已下载的加密音频可从浏览器缓存读取。支持进度条、倍速、逐句精听、词语定位和名词听写。
- 话题语料的「日常生活与社交（填空题部分）」收录指定的 9 个 Part，可逐段听写、核对答案、查看原句含义并收藏生词。
- 生词本可自行添加词汇，区分阅读词汇、听力语料和听力名词。切换模块后可回到此前打开的文章或听力 Part。

## 使用与数据

在手机浏览器打开 [网站](https://bkaaam.github.io/-/)，输入密码即可。建议用同一个浏览器学习并定期备份；清理浏览器网站数据会删除本机学习记录。新版沿用原有的 `ielts-room-v2` 数据库及 `notes`、`vocab` 存储项，没有重置旧生词和笔记。网站的可用速度也取决于当前网络与 GitHub Pages 的连通性。

原文来自用户提供的资料，部分内容经 OCR 识别，可能有识别误差；翻译、小结和词义提示为辅助学习内容。录音与文字的词级定位由声学对齐生成，个别边界可能偏移。仓库仅放加密后的学习资料，不包含原始 PDF 和明文密码。

## 项目结构

- `site/`：GitHub Pages 静态网站及加密资料。
- `site/fast.js`：分章节加载、缓存及解密。
- `site/study-tools.js`：阅读段落、标记笔记、音质切换等学习工具。
- `processing/`：本地资料处理和校验脚本；不随网站部署。
- `.github/workflows/pages.yml`：推送到 `main` 后部署 GitHub Pages。
