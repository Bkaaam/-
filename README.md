# 雅思阅读与听力精听阅读器

[打开网站](https://bkaaam.github.io/-/) · [话题语料](https://bkaaam.github.io/-/#topics) · [查看发布状态](https://github.com/Bkaaam/-/actions)

一个适合安卓手机浏览器使用的个人雅思学习网页。打开网页后输入已约定的六位密码即可使用，无须注册或登录 GitHub。网站以 GitHub Pages 发布；能否连通取决于所在网络。

## 本版功能

- **阅读书架**：剑桥雅思 11–21 Academic，共 132 篇，按册、Test、Passage 1–3 查找。每句后有中文句意与自动生成的结构提示；轻触单词查看音标、释义和读音，也可以长按并划选词句，查看它所在句子的语境翻译。阅读页不显示参考答案。
- **听力精听**：剑桥雅思 11–21 共 176 个 Part。录音支持拖动进度、调速、逐句重听和已定位单词的原声跳转。新增“名词听写”：按句听音，输入名词后核对；写错的名词收入生词本的“听力名词”。
- **日常生活与社交（填空题部分）**：只选剑 11 T1 Part1、T2 Part1；剑 13 T2 Part1、T3 Part1；剑 14 T1 Part1；剑 16 T2 Part1、T3 Part1；剑 17 T2 Part1、T3 Part1。九段各自独立练习，剑 14 T1 Part1 与剑 16 T3 Part1 标为补充，其余为重点。196 条词语或表达包含 90 个答案词及常见听力表达。听写可选 0.8、1、1.2、1.5 倍速；确认后直接显示答案、原句、句意和雅思场景提示，无需先写对。可收藏到“听力语料库”。
- **生词本**：分别显示“阅读生词汇”“听力语料库”“听力名词”“其他听力生词”。原有阅读和听力收藏保留在原来的浏览器数据中，不改变数据库名称与既有数据格式。
- **手机界面**：适配小米浏览器、Microsoft Edge 和 Chrome 的窄屏触控布局；可以从浏览器菜单添加到桌面。

## 使用方法

1. 用手机浏览器打开 [网站](https://bkaaam.github.io/-/)，输入你已设置的密码。
2. 阅读时轻触单词查词，长按并拖动选中词句查看上下文译文。每句下方直接显示句意与阅读提示。
3. 听力页可开启“逐句精听”或“名词听写”。话题页先选一段 Part，再做该段的听音练习。
4. 在“设置”中定期导出生词与学习进度。记录只保存在当前浏览器；更换手机或清理浏览器数据前请备份。

## 资料、准确性和隐私

网站只发布加密后的文章、答案、录音、词典和学习资料，网页源码中没有明文密码。六位数字密码的强度有限，知道密码的人也能解锁。原始 PDF 与未加密资料没有放进这个公开仓库。

原文由提供的 PDF 扫描识别，少量文字可能有识别错误。逐句中文译文由 [Argos Translate](https://github.com/argosopentech/argos-translate) 英中离线模型辅助生成；句子分析、名词提取和声学时间轴也是自动生成，需结合原书及录音核对。17 个答案词在 OCR 原文中未能可靠定位，网站会明确标记，仍可学习答案和听整段原声。模型采用 CC BY 4.0 许可；本仓库只包含生成的加密学习资料，不包含模型文件。英汉词典和音标来自 [ECDICT](https://github.com/skywind3000/ECDICT)，许可见 `site/dictionary-LICENSE.txt`。

浏览器学习记录使用原有 `ielts-room-v2` IndexedDB 的 `notes` 和 `vocab` 两项。网站更新不会清除它们；无痕模式、清理网站数据或更换浏览器仍会丢失本机记录，因此请用设置页备份。

## 项目结构

- `site/`：网页与加密资料；GitHub Pages 从这里自动发布。
- `site/app.js`：书架、单词查询、播放器、学习进度。
- `site/upgrade.js`：逐句译文、划选翻译、名词听写与分类生词本。
- `site/topics.js`：九段独立的话题听写。
- `.github/workflows/pages.yml`：推送到 `main` 后自动更新网站。

本仓库只用于这一个网站。未来增加话题时，按“话题名称 + 剑几 / Test / Part”收集新的资料组。
